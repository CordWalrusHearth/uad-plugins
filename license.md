## ❓ What Is UAD

| **Term** | **Description** |
|-----------|-----------------|
| **UAD-2** | DSP accelerator card |
| **Apollo** | Audio interface + DSP |
| **UAD Plugin** | Emulation running on DSP |
| **Console** | Apollo routing app |
| **iLok** | License manager |
| **Native** | Runs on your CPU |

**Why use it?**
- ✅ Authentic analog emulations
- ✅ Ultra-low latency tracking
- ✅ Runs on dedicated DSP
- ✅ Trusted by studios worldwide
- ✅ Free guide
